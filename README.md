# Scotiabank Special Offers — Master Sheet

A single-page reference to every live Scotiabank Canada personal banking promotion,
with the exact qualifying steps, date windows, payout timing, exclusions, and a
source link for each.

**Live site:** https://daveqwerty1007.github.io/site/

## What's here

| File | Purpose |
|---|---|
| `index.html` | The sheet. Self-contained — no build step, no dependencies. |
| `data/snapshot.json` | Structured baseline of all 17 offers. This is what the bi-weekly check diffs against. |
| `CHANGELOG.md` | Append-only log of what changed at each re-check. |
| `.nojekyll` | Tells GitHub Pages to serve files as-is. |

## Updating

The sheet is regenerated by a scheduled Claude task that re-fetches Scotiabank's
public pages, diffs them against `data/snapshot.json`, and flags changes. Each run
updates `index.html`, `data/snapshot.json`, and appends to `CHANGELOG.md`.

## Caveat

Summaries are condensed from Scotiabank's public pages. The full legal terms on
those pages govern. Not financial advice.
